檔案 01：廢土上的回收者

解密日期: 2026.04.12 // 記錄人: 管理員

在塔洛斯-II 龐大的未知區域中，「協議回收」是一項高風險的工作。 舊時代留下的技術設施往往被侵蝕體或異化生物包圍，而洛西正是終末地工業中最值得信賴的協議專家之一。 她並不高大，但每次行動都能以驚人的冷靜完成前線挺進與系統重啟。 根據同組隊員的評語，洛西在戰鬥中幾乎從不流露多餘的情緒，但在回收完一項關鍵協議組件後，她總會輕輕撫摸設備殼體上的終末地徽標。

檔案 02：終末地協議裝具「閃雷」

解密日期: 2026.05.01 // 記錄人: 裝具整備組

洛西所使用的雙刃戰術裝具，並非標準的冷兵器，而是直接連通終末地高壓電路核心的電磁兵器。 刃身採用高密度複合合金鑄造，可在 0.05 秒內升溫並施加超過 50,000 伏特的脈衝電流。 這套裝具對使用者的神經反應要求極高，洛西是極少數能完整承受其電磁反衝力的特別行動隊成員。
